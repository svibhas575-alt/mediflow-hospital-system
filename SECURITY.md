# Security policy

MediFlow is an educational/local-use project and is not suitable for real patient information or public production deployment.

Do not submit real patient data, credentials, API keys, or database files in issues or pull requests. For a suspected security issue, contact the repository maintainer privately through the contact method listed on the GitHub profile rather than publishing exploit details in a public issue.

Before any real-world use, the application requires professional security, privacy, clinical, and regulatory review, including authentication, authorization, secure session management, encryption, backups, audit controls, and deployment hardening.
