# Contributing to MediFlow

Thanks for your interest in improving MediFlow.

## Before making changes

1. Fork the repository and create a feature branch.
2. Use Python 3.10 or newer.
3. Create a virtual environment and install dependencies with `python -m pip install -r requirements.txt`.
4. Run the application locally and verify the affected workflow.

## Pull requests

- Keep changes focused and describe the problem they solve.
- Include clear reproduction steps for bug fixes.
- Do not commit databases, credentials, `.env` files, or real patient information.
- Use synthetic data only. MediFlow is an educational/local-use project and is not certified for clinical use.
